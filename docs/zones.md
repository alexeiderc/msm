# Zonas, Provincias Y Municipios

Toda publicacion visible debe tener zona real.

## Reglas publicas

Un producto o servicio solo aparece si tiene:

- vendedor o tienda VIP;
- provincia o estado;
- municipio o ciudad;
- estado activo;
- tienda activa;
- categoria;
- precio;
- imagen o placeholder MSM.

Si falta alguno, queda como borrador.

## Uso operativo

Las zonas controlan:

- productos;
- servicios;
- remesas;
- cambios;
- liquidez;
- capacidad diaria;
- asignacion VIP;
- futuros Cajeros MSM.
