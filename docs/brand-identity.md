# Identidad MSM MY STORE

Fuente revisada:

- `MANUAL DE ID SORIA.pdf`
- Logos enviados por el usuario el 2026-06-20

## Paleta oficial

- Azul primario: `#197BD2`
- Azul profundo: `#0C3F6A`
- Negro institucional: `#14171A`
- Gris institucional: `#657786`
- Gris claro: `#E6E7E8`
- Blanco: `#FFFFFF`

## Tipografia

El manual indica Helvetica / Helvetica Neue LT Std. En web se usa:

```css
font-family: Helvetica, "Helvetica Neue", Arial, sans-serif;
```

## Logo

El logo principal debe usarse azul sobre blanco. La version blanca queda reservada para fondo azul o imagen oscura con contraste suficiente.

Asset local usado en la aplicacion:

```text
public/brand/msm-my-store-logo.jpeg
```

## Reglas aplicadas en la app

- Se retiro la paleta inicial verde/dorada.
- Los CTA principales usan azul profundo `#0C3F6A`.
- Los acentos, iconos y estados positivos usan azul primario `#197BD2`.
- Fondos y bordes usan gris claro institucional.
- Se evita degradado, sombra fuerte, rotaciones o alteraciones del logo.
