# PROJECT MASTER - La Maquina del Futuro

## Identidad del Proyecto

- **Nombre:** La Maquina del Futuro
- **Empresa:** MSM MY STORE LLC
- **Propietario:** Miguel Soria Martinez
- **Tipo:** Plataforma web de visualizacion temporal consciente
- **Estado:** MVP funcional

## Vision

Crear la primera plataforma del mundo que una inteligencia artificial, meditacion guiada, escritura de vision, entrevistas futuras, prototipos tecnicos, pitch para inversionistas y fe para ayudar a las personas a construir sus ideas antes de empezar.

## Mision

Herramienta tecnologica que transforma visiones en planes accionables usando IA, meditacion, escritura y prototipos.

## Pilares

1. **Fe** - Base espiritual con versiculos biblicos y oracion de uncion
2. **IA** - Generacion de contenido con OpenAI
3. **Visualizacion** - Meditacion guiada y entrevista futura
4. **Documentacion** - Vision, prototipo, pitch, libro
5. **Inversion** - Investor Room privado para inversionistas

## Stack Tecnologico

| Capa | Tecnologia |
|------|-----------|
| Frontend | Next.js 15, React, TypeScript, Tailwind CSS |
| Backend | Supabase, PostgreSQL, Edge Functions |
| IA | OpenAI API (GPT) |
| Auth | Supabase Auth |
| Storage | Supabase Storage |
| Deploy | Vercel |

## Modulos del MVP

1. Landing page publica `/maquina-del-futuro`
2. Dashboard principal `/dashboard/maquina-del-futuro`
3. Vision Wizard (9 pasos)
4. Generacion IA (meditacion, entrevista, prototipo, pitch)
5. Investor Room privado
6. Libro por capitulos
7. Declaraciones Yo Soy
8. Base espiritual (scriptures + oracion)

## Flujo del Usuario

```
1. Entra a la landing
2. Crea cuenta / inicia sesion
3. Va al dashboard
4. Crea una vision con el Wizard (9 pasos)
5. La IA genera vision completa
6. Genera meditacion guiada
7. Genera entrevista futura
8. Genera prototipo tecnico
9. Genera pitch para inversionistas
10. Crea Investor Room con link privado
11. Escribe capitulos del libro
12. Guarda declaraciones Yo Soy
```
