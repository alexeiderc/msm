ELIANA.MSMMYSTORE.COM - LA INCUBADORA DEL FUTURO

1. Instalar
   npm install

2. Crear el archivo .env a partir de .env.example.
   No publiques .env ni ninguna API key en GitHub, ZAFIRO o el navegador.

3. Cuentas gratuitas (las crea el propietario):
   - Groq: https://console.groq.com/keys
   - Gemini: https://aistudio.google.com/app/apikey
   - Supabase: https://supabase.com/dashboard

4. Base de datos
   En Supabase abre SQL Editor y ejecuta completo supabase.sql.
   Usa SUPABASE_URL y la Service Role Key solo en .env del servidor.

5. Arrancar en la computadora
   npm run dev
   Abrir: http://localhost:369
   Salud de API: http://localhost:369/api/health

6. Produccion
   - Subir esta carpeta a un proyecto Node.js en el hosting elegido.
   - Definir las mismas variables de .env como secretos de produccion.
   - Conectar el dominio eliana.msmmystore.com al proyecto.
   - Configurar CORS_ORIGINS con zafiro.msmmystore.com y marketplace.msmmystore.com.

7. Integrar en ZAFIRO
   Agrega antes de </body> en el sitio ZAFIRO:
   <script src="https://eliana.msmmystore.com/widget.js" defer></script>

   Durante pruebas locales desde otro puerto:
   <script>window.ELIANA_WIDGET_URL = "http://localhost:369";</script>
   <script src="http://localhost:369/widget.js" defer></script>

8. Membresias
   Gratis: 5 mensajes, una mente Groq.
   Iniciado: 100 mensajes, Groq + Gemini + fusion ELIANA.
   Dueno: 500 mensajes y espacio para incubar un proyecto.
   Maestro: ilimitado y arquitectura lista para siete mentes.

   Despues de confirmar un pago, activar manualmente desde Supabase:
   update public.membresias set plan = 'iniciado' where email = 'correo@cliente.com';

9. Operacion responsable
   El modo local funciona sin claves, pero su memoria se pierde al apagar el servidor.
   Con Supabase se guardan membresias y conversaciones.
   Las respuestas IA son asistencia; pagos, decisiones legales, salud y operaciones sensibles requieren revision humana.
