# Sistema De Diseno MSM MY STORE

El rediseño usa una base mobile first, plana, moderna y comercial.

Archivo central: `src/lib/design-system.ts`.

Colores principales:

- `#197BD2` azul MSM.
- `#0C3F6A` azul oscuro.
- `#14171A` negro texto.

## Reglas visuales

- Mobile first.
- Header limpio con buscador.
- Navegacion inferior movil con iconos outline.
- Cards premium con imagen clara, precio visible, rating, municipio, vendedor y CTA.
- Estados empty/loading/error reutilizables.
- Bordes maximo 8px en cards.
- Sombras suaves y hover ligero.
