# Guia Visual MSM MY STORE

## Marca publica

La marca visible es **MSM MY STORE**. En interfaz comercial se usa `MSM my store` para respetar el estilo del logo.

## Colores

- Azul primario: `#197BD2`
- Azul oscuro: `#0C3F6A`
- Negro: `#14171A`
- Gris: `#657786`
- Gris claro: `#E6E7E8`
- Blanco: `#FFFFFF`

## Estilo

- Futurista, limpio y profesional.
- Fondos tecnologicos azules con brillo sutil.
- Logo legible, sin deformar.
- Botones claros.
- Mobile first.
- Sin publicar datos privados de pago.

## Eslogan

`Rapidez - Excelencia - Seguridad`
